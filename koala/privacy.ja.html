アプリ：旅のしおり（開発コード名 koala）

このアプリは採用選考のためのポートフォリオです。この文書は、アプリが扱うデータを説明するためのもので、法律の専門家の確認は受けていません。

この文書は、アプリに同梱しています。インターネットに接続していなくても読めます。

運営者は、個人開発者（GitHub：akmoor25）です。この文書は、アプリのコードと設定で確かめた事実だけを書いています。

1. 取得する情報

1.1 端末の中だけに保存するもの

次の情報は、この端末の中にだけ保存し、運営者には送りません。

  • あいことばの平文：しおりを「共同編集にする」オーナーが決めたあいことばです。QR コードをあとで見せるために、端末の暗号化された保存領域（Android Keystore、iOS Keychain）に保存します。端末を替えると失われます。
  • しおりなどのキャッシュ：オフラインでも読めるように、読んだしおり、旅程、メモが端末に残ります。
  • ホーム画面ウィジェットのデータ：しおりのタイトルと、今後の最大 20 件の予定（タイトル、備考、開始と終了の時刻、タイムゾーン、移動手段のアイコン）です。ウィジェットがアプリを開かずに表示するために、端末に保存します。
  • フォントのキャッシュと、Firebase が端末に作るログイン状態などの情報。

1.2 サーバーに送るもの

アプリは、「はじめる」を押すと、Google が提供する Firebase に接続します。アカウントの登録は要りません。Crashlytics の送信と、FCM の自動の準備は、「はじめる」を押すまで、設定で止めてあります。次の情報が、サーバーに送られます。

情報内容と送られるとき
匿名のユーザー ID「はじめる」で、Firebase Authentication が、端末ごとに作る意味のない文字列です。名前、メールアドレス、電話番号は取得しません。
ニックネーム共同編集を有効にするとき、しおりに参加するとき、メニューで入力します。既定値は、端末の機種名（Pixel 10a など）です。端末に付けた名前は使いません。Firebase Authentication に保存されます。
しおりタイトル、表紙の絵文字、色、期間とタイムゾーン、オーナーの匿名 ID、共同編集中かどうか、作成時刻。サンプルのしおりを追加したときも同じです。
旅程タイトル、備考、リンク、日時、タイムゾーン、移動手段のアイコン。
メモ本文（書式つきのテキスト）。
カーソル共同編集のメモを開いている間の、時刻、ニックネームの先頭 1 文字、カーソルの位置。
メンバーの記録しおりごとの、参加者の匿名 ID。参加者には、あいことばのハッシュが入ります。自分のしおりの一覧（匿名 ID ごとの索引）も保存されます。
あいことばのハッシュあいことばの平文は送りません。しおり ID を塩にして SHA-256 を 1 万回かけた値だけを保存します。
通知の宛先通知を許可したとき、この端末の FCM のトークン、OS の種類（android か ios）、時刻を、匿名 ID に結び付けて保存します。
閉鎖の記録オーナーが、しおりを削除したとき、共同編集を停止したときに、種類、しおりのタイトル、時刻を書きます。参加者に正しい通知を出すためです。
通知の送信の記録同じ通知が 2 回届かないようにするための記録（イベントごと、端末のトークンのハッシュごと）と、連打を抑えるための時刻です。
通知の内容種類、しおり ID、しおりのタイトル、ニックネームを、FCM（iOS では Apple の APNs も）を通して宛先の端末に送ります。サーバーは、通知の内容を保存しません。
不具合の情報アプリでエラーが起きたとき、またはアプリが落ちたときに、Firebase Crashlytics に送ります。エラーの内容とスタックトレース、ビルドしたコミットを、アプリが付けます。Crashlytics の SDK が、端末の機種、OS、アプリのバージョンと、インストールごとの識別子（Crashlytics Installation UUID、Firebase installation ID）を自動で付けます。しおりの内容など、あなたが入力した情報は送りません。
サーバーの記録通知と掃除の関数の実行の記録（イベント ID、しおり ID、件数、エラーのコード、想定外のエラーのときは匿名のユーザー ID など）が、Google Cloud のログに残ります。ニックネームとしおりのタイトルは、記録に出しません。
通信に伴う情報Google のサービスは、安全のために、IP アドレスや User-Agent を扱います（Firebase Authentication は、記録した IP アドレスを数週間保持します。Google の説明による）。

1.3 取得しないもの

  • 氏名、メールアドレス、電話番号、位置情報、連絡先、広告 ID。位置情報と連絡先の権限は、アプリに入っていません。広告 ID の権限は、取り除いています。
  • 利用状況の分析（Firebase Analytics など）。使っていません。
  • カメラの映像。QR コードを読み取るときだけカメラを使い、画像を保存も送信もしません。

1.4 外部への通信

  • Firebase（Authentication、Realtime Database、Cloud Messaging、Crashlytics）との通信。
  • フォントの取得：アプリは、画面の文字に使うフォント（BIZ UDPGothic）を、初めて表示するときに、Google のフォント配信サービスから取得します。このとき、通信の相手（Google）に、IP アドレスなどの通信に伴う情報が届きます。
  • 旅程のリンクとメモの中のリンクは、あなたがタップしたときだけ、ほかのアプリ（ブラウザなど）で開きます。
  • この文書は、アプリに同梱しているので、読むときに通信はしません。文書の中のリンク（運営者の GitHub、Firebase の説明）は、あなたがタップしたときだけ、ほかのアプリ（ブラウザなど）で開きます。

2. 利用目的

  • しおり、旅程、メモを保存し、共同編集で、参加者に見せるため。
  • 誰がしおりの持ち主か、参加者かを区別し、他人のしおりを読み書きできないようにするため（匿名 ID）。
  • 参加、脱退、しおりの削除、共同編集の停止を、プッシュ通知で知らせるため（ニックネーム、通知の宛先）。
  • 同じ通知が 2 回届かないようにするため（通知の送信の記録）。
  • 不具合の原因を調べて、直すため（不具合の情報）。
  • 使われなくなったデータを消して、容量を空けるため（毎日の掃除）。

この目的の範囲を超えて使うことはなく、広告やマーケティングには使いません。

3. 保存先と、外部への委託

データの保存と処理は、Google が提供する Firebase と Google Cloud に任せています。

  • Realtime Database（しおり、旅程、メモなど）と Cloud Functions（通知と掃除）：アジア太平洋（シンガポール、asia-southeast1）。
  • Firebase Authentication、Firebase Cloud Messaging、Firebase Crashlytics：保存する地域を、運営者は指定していません。Google が運用する地域に保存されます。日本国内や、アジアの中だけとは限りません。
  • iOS の通知は、Apple の APNs を通ります。

Google の取り扱いは、Firebase のプライバシーとセキュリティに書かれています。

4. 第三者への提供

運営者は、あなたの情報を、広告や販売のために第三者へ提供しません。ただし、次の場合は除きます。

  • 法令に基づいて、開示を求められた場合。

なお、次の人には、アプリの仕組みとして情報が見えます。

  • 同じしおりのメンバー：しおり、旅程、メモ、メンバーのカーソル（ニックネームの先頭 1 文字）。メンバーの匿名 ID も、カーソルの記録を通して見えます。
  • オーナー：自分のしおりのメンバーの匿名 ID。オーナーへの通知には、参加または脱退したメンバーのニックネームが出ます。参加者への通知には、削除または停止したオーナーのニックネームが出ます。
  • 運営者：Firebase のコンソールで、保存されているデータを見られます。

QR コードには、しおり ID とあいことばが入っています。QR コードを読み取った人は、誰でも参加できます。信頼できる相手にだけ見せてください。

5. 保存期間と削除

情報保存期間と、消えるとき
しおり、旅程、メモ、メンバーの記録、あいことばのハッシュ、カーソルしおりは、オーナーが削除するか、採用選考の終了後の一括削除まで保存されます。
そのほかに、毎日 4:00（日本時間）の掃除が、持ち主の匿名アカウントが Firebase Authentication からなくなったしおりと、その関連データを消します。参加者が残っていても消します。しおりが古いというだけでは消しません。
カーソルは、アプリが背面に移るか、接続が切れると消えます。
匿名のユーザー ID、ニックネームメニューの「アカウントとデータを削除」で、あなたが削除できます（6 章）。削除しないときは、Firebase のコンソールで、運営者がユーザーを削除するまで残ります。削除したあと、Google のシステム（バックアップを含む）から消えるまで、最長 180 日かかります（Google の説明による）。
FCM のトークン送信のときに無効と分かると、自動で消えます。「アカウントとデータを削除」を使うと、サーバーのトークンを全て消し、FCM のトークンも破棄します。匿名アカウントがなくなったあとは、掃除で消えます。
閉鎖の記録通知を決めたあとに、関数が消します。共同編集のメンバーがいない状態で停止したときは、通知の処理が動かないため、しおりが残る間、記録も残ることがあります。しおりが消えるときに、掃除で消えます。
通知の送信の記録作られて 1 日以上たったものを、毎日の掃除で消します。掃除は 1 日 1 回なので、最長でおよそ 2 日残ります。
不具合の情報（Crashlytics）Google が、90 日保存します（スタックトレースと識別子）。90 日たつと、削除の処理が始まります。
サーバーの記録（Cloud Logging）Google Cloud の既定では 30 日です。
端末の中の情報アプリを削除すると消えます。あいことばの平文は、しおりを削除するか、共同編集を停止したときにも消えます。サーバー側の掃除でしおりが消えたときは、端末のあいことばは残ります。ホーム画面ウィジェットのデータは、そのしおりを削除するか、そのしおりから抜けると消えます。しおりなどのキャッシュは、「アカウントとデータを削除」のあとも、アプリを削除するまで、端末に残ることがあります。

採用選考の終了後

採用選考の終了後、速やかに削除します。通知と掃除の関数を止め、Realtime Database の全データと、匿名ユーザーを削除します。必要なら、Firebase のプロジェクトごと削除します。終了後は、配布した APK から Firebase に接続できなくなり、共同編集とメモの保存はできなくなります。

Google の説明では、Firebase Authentication と FCM のデータは、削除の操作をしたあと、最長 180 日かけて、Google のシステム（バックアップを含む）から消えます。

6. 利用者ができること

  • アカウントとデータを削除する：メニューの「アカウントとデータを削除」から、あなたの匿名アカウントと、サーバーにあるあなたのデータを削除できます。次の順に行います。
    1. あなたがオーナーのしおりを、全て削除します（参加者は、そのしおりにアクセスできなくなり、削除の通知が届きます）。
    2. あなたが参加しているしおりから、抜けます（オーナーに、脱退の通知が届きます）。
    3. しおりの索引と、通知の宛先（FCM のトークン）を消し、端末の FCM のトークンを破棄します。
    4. 匿名のユーザー ID とニックネームを、Firebase Authentication から削除します。
    削除すると、元には戻せません。同じ端末でも、次に「はじめる」を押すと、新しい匿名のユーザー ID になり、前のしおりには戻れません。途中で失敗したときは、アカウントは削除されません。もう一度、同じ操作をしてください。
    削除しても残るもの：他の人のしおりに、あなたが書いた旅程とメモ（書いた人を記録していないため）。通知の送信の記録（最長でおよそ 2 日）。不具合の情報（Google が 90 日保存）。サーバーの記録（Google Cloud の既定で 30 日）。端末の中のキャッシュ（アプリを削除すると消えます）。
  • しおりから抜ける：参加者は、しおりから抜けられます。あなたが書いた旅程とメモは、しおりに残ります。
  • しおりを削除する、共同編集を止める：オーナーは、自分のしおりを削除するか、共同編集を停止できます。
  • 端末のデータを消す：アプリを削除すると、端末の中のデータが消えます。サーバーのデータは、消えません。サーバーのデータも消すときは、先に「アカウントとデータを削除」を使ってください。
  • それでも消えないとき：アカウントの削除に失敗し続けるなど、アプリから消せないときは、7 章の問い合わせ先に連絡してください。

しおりに入れた情報は、同じしおりのメンバーに見えます。大切な情報は入力しないでください。
